Voice Design（文章で声を作る）

声の特徴を文章で書き、seed を固定して候補を作ります。気に入ったら名前を付けて参照音声として保存できます。

Strata（Qwen3.8-Flash-Next）の推奨条件
同梱の LLM より返答の質が大幅に上がります。同梱プロファイルが high（VRAM 20GB 以上かつ RAM 48GB 以上）で、ディスクに約 80GB の空きがある PCで推奨します （Strata 自体の要件は VRAM 12GB・RAM 48GB・ディスク約 80GB。RAM 32GB では Coder 版しか載らず、日本語の雑談に弱いので推奨しません）。 別ソフトウェアで（ライセンスは Strata 側）、1 リクエストずつしか処理せず、起動時に 1〜3 分 PC が重くなります。 導入は setup.bat --llm strata、すでに入っているときは下の「自分で用意した推論サーバー」でプリセット「Strata」を選びます。

LLM の方式

モデル（同梱の llama-server）

接続先（外部の推論サーバー）

外部サーバーは start.bat では起動しません。先に起動しておいてください（起動を最大 2 分待ちます）。
直列化: 同じ GPU で LLM と TTS を動かす場合はオン（取り合いを防ぎ、最初の音声が早くなる）。別の PC やクラウドの LLM ならオフが目安です。
このサーバーはインターネット上（または別のネットワーク）にあります。会話の内容が外部のサービスに送られます。

temperature と思考の設定は次のメッセージから反映されます。モデル・方式・接続先・コンテキスト長を変えたときは再起動が必要です（「保存して再起動」、または start.bat の再実行）。

成人キャラクターのみ。 年齢は必須で、18 歳未満、または「少女」「中学生」など未成年を示す設定は保存できません。
