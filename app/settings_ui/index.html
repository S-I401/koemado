Strata（Qwen3.8-Flash-Next）の推奨条件
同梱の LLM より返答の質が大幅に上がります。VRAM 12GB 以上・RAM 48GB 以上で、ディスクに約 80GB の空きがある PCで推奨します（同梱プロファイルが mid でも high でも）。 VRAM が 12〜19GB だと専門家のキャッシュが小さくなり、速度は下がります（Strata の README の実測: RTX 5070 12GB・RAM 64GB で IQ2_XS 約 79 tokens/s）。RAM 32GB では Coder 版しか載らず、日本語の雑談に弱いので推奨しません。 別ソフトウェアで（ライセンスは Strata 側）、1 リクエストずつしか処理せず、起動時に 1〜3 分 PC が重くなります。 導入は setup.bat --llm strata、すでに入っているときは下の「自分で用意した推論サーバー」でプリセット「Strata」を選びます。

LLM の方式

モデル（同梱の llama-server）

接続先（外部の推論サーバー）

外部サーバーは start.bat では起動しません。先に起動しておいてください（起動を最大 2 分待ちます）。
直列化: 同じ GPU で LLM と TTS を動かす場合はオン（取り合いを防ぎ、最初の音声が早くなる）。別の PC やクラウドの LLM ならオフが目安です。
このサーバーはインターネット上（または別のネットワーク）にあります。会話の内容が外部のサービスに送られます。
名前と違って、高速化の機能ではありません。Strata に同梱の制御ベクトルで、モデルの「拒否の方向」を取り除きます。 オンにすると、モデルが依頼をほとんど断らなくなります（安全上の振る舞いが外れます）。速度は 1 トークンあたり 0.2〜0.4% 遅くなる程度です。 出力の責任は利用者にあります。ベクトルは Qwen3.8-Flash-Next 専用です（Swift 1.5・Coder 版・Unsloth 版では使えません）。ライセンスは Qwen Community License 1.0 です。 キャラクターは成人のみ、という制限は、この設定とは関係なく有効なままです。

キャラクター

キャラクター画像（立ち絵）

PNG（透過がおすすめ）。会話画面に表示されます。image_joy.png のような表情別の画像があれば、表情に応じて切り替わり、無い表情は基本の 1 枚のままです。画像が無いときはシルエットが出ます。

ツールの変更は、再起動したときに反映されます（ツールの定義は起動時に固定します。会話の途中で変わると、LLM のプロンプトキャッシュが効かなくなるためです）。
いまの LLM 設定では「ツール呼び出しを使う」がオフです。ここで有効にしても、どのツールも使われません（LLM タブの外部サーバーの設定）。

標準のツール

検索語は外部（DuckDuckGo）に送られます。ページの本文を読む web_fetch は、この PC や社内ネットワークのアドレス（127.0.0.1・10.x・192.168.x・file:// など）を拒否し、サイズ（1MB）と時間（15 秒）にも上限があります。 ネットワークに出したくないときはオフにしてください。

スキル

スキルは、手順を書いた skills/<名前>/SKILL.md です。プロンプトには一覧（名前と description）だけを入れ、手順の本文は LLM が必要なときに use_skill で読みます（プロンプトが短く保たれ、キャッシュも壊れません）。起動時に読み込みます。

MCP サーバー

MCP のツールは、この PC で動くプログラムです。ファイルの操作やコマンドの実行ができるものもあります。音声は聞き間違えることがあり、聞き間違いがそのまま実行される可能性があります。 信頼できるサーバーだけを追加し、「使うツール」を必要なものだけに絞ってください。
・ツールが多いと、小さい LLM では呼び出しが不安定になります。目安は、標準のツールを含めた合計で、同梱の low（E4B）は 8 個程度まで、mid（26B-A4B）は 15 個程度まで、大きいモデル（Strata・クラウド）でも 30 個程度までです。
・反映には再起動が必要です（ツールの定義が会話の途中で変わると、プロンプトキャッシュが効かなくなるため）。
・npx で動かすサーバーには Node.js が必要です（自動では入れません）。
サーバーを追加

config/mcp.json（Claude Desktop と同じ形式。そのまま貼り付けられます）

各サーバーに "enabled": false と "allowed_tools": ["ツール名", …]（省略するとすべて許可）を足せます。env・headers の値は、画面では伏せ字です（伏せ字のまま保存すると、保存済みの値が残ります）。

外部エージェント

時間のかかる作業（ファイル操作・コード実行・長い調査）だけを、別の作業エージェントに頼みます。天気と簡単な検索は、アバター自身のツールで済ませます。頼んだあとも会話は続けられ、完了すると結果をアバターが話して伝えます。

Hermes の API は、ターミナルの実行を含む全ツールへのアクセスを与えます。127.0.0.1 の中だけで使い、API キーを必ず設定してください。Hermes 側の承認設定は緩めないでください。 Hermes 本体のインストールは、このアプリの対象外です（Hermes Agent の公式ドキュメント）。
127.0.0.1 以外の宛先です。通信が暗号化されない相手に、この PC の会話の内容を送ることになります。
API キーが未設定です。キーなしで使うのはおすすめしません。
